# AXOM web application

React, TypeScript, Vite and Zustand. Start from the [repository README](../README.md)
for installation and [frontend map](../docs/architecture/frontend.md) for code entrypoints.

```sh
npm ci
npm run dev
```

Local Vault persistence and JSON backup work without cloud configuration.
See [development](../docs/operations/development.md) for optional accounts/native setup
and [testing](../docs/operations/testing.md) for checks.
The canonical Tauri shell is `../src-tauri/`; this subtree's old native scaffold is historical.
